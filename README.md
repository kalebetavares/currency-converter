# Currency Converter

A lightweight and framework-free currency conversion application built with pure Java 11, designed to fetch real-time exchange rates using the public **AwesomeAPI**.  
API documentation: https://docs.awesomeapi.com.br/api-de-moedas

---

## 🚀 Features
- Bidirectional currency conversion:
  - **BRL ↔ USD**
  - **BRL ↔ EUR**
  - **USD ↔ EUR**
- Input validation and error handling
- Clear domain boundaries following SOLID principles
- Fully tested using TDD

---

## 🧠 Principles Applied
- **TDD (Test-Driven Development)**
- **Clean Code**
- **SOLID Principles**

---

## 🛠️ Technologies Used
- **Java 11**
- **JUnit 5**
